## Document purpose

This document turns the Agent 1 investigation tracks into a concrete product plan: prioritised features, architectural patterns grounded in the current codebase, UI wireframes, a backward-compatible `config.json` v2 schema, and a phased roadmap for v1.1 → v1.2 → v2.0.

**v1 constraints that shape every recommendation**

| Area | Today |
| :--- | :--- |
| UI | `customtkinter` dual-pane: left ~300 px control panel, right 16:9 preview (`PREVIEW_W/H = 800×450`) |
| Wallpaper | `set_windows_wallpaper()` → Registry `WallpaperStyle`/`TileWallpaper` + `SystemParametersInfoW(SPI_SETDESKWALLPAPER)` — **global**, not per-monitor |
| Slideshow | `self.after()` timer; deck = `self.images` from **one** selected folder; shuffle = `random.choice` excluding current index |
| Preview | Synchronous Pillow `.draft("RGB", …)` + `.thumbnail(…, LANCZOS)` on the UI thread |
| Config keys | `folders`, `current_folder`, `current_image`, `style`, `interval`, `shuffle` |
| Planned (code/README) | `pystray` tray daemon; multi-monitor via modern APIs |

## 2. Architectural Blueprints & Code Snippets

All samples use British English comments and align with today’s shapes: `DesktopVista(ctk.CTk)`, `self.after` / `self.after_cancel`, `self.images` / `self.index`, `set_windows_wallpaper`, `list_images`, `PREVIEW_W/H`, `load_config` / `save_config`.

### 2.1 `pystray` + CustomTkinter coexistence

**Problem:** `pystray` wants its own blocking icon loop; `customtkinter` owns the main thread via `mainloop()`. Running both on one thread deadlocks.

**Pattern:** Keep Tk on the main thread. Run the tray icon in a **daemon** thread. Route every tray action back onto Tk with `self.after(0, …)` so UI and wallpaper calls stay thread-safe.

```python
# Illustrative pattern for Desktop Vista — embed in desktop_vista.py later;
# do not treat as a drop-in rewrite of the current file.

import threading
from PIL import Image as PilImage  # tray needs a small RGBA icon

try:
    import pystray
    from pystray import MenuItem as Item
except ImportError:
    pystray = None


class DesktopVistaTrayMixin:
    """Coexists with DesktopVista's existing self.after slideshow jobs."""

    def _start_tray(self) -> None:
        if pystray is None:
            self._set_status("Install pystray for system-tray support.")
            return

        # Prefer a branded .ico beside the app; fall back to a tiny placeholder.
        icon_path = APP_DIR / "assets" / "desktop_vista.ico"
        if icon_path.exists():
            image = PilImage.open(icon_path)
        else:
            image = PilImage.new("RGBA", (64, 64), (0, 120, 215, 255))

        menu = pystray.Menu(
            Item(lambda text: self._tray_current_label(), lambda: None, enabled=False),
            Item("Next wallpaper", lambda: self._tray_call(self._tray_next_and_set)),
            Item("Previous wallpaper", lambda: self._tray_call(self._tray_prev_and_set)),
            Item("Pause / Resume slideshow", lambda: self._tray_call(self._toggle_slideshow)),
            Item("Reveal current in Explorer", lambda: self._tray_call(self._reveal_current)),
            pystray.Menu.SEPARATOR,
            Item("Open Desktop Vista", lambda: self._tray_call(self._restore_from_tray)),
            Item("Exit", lambda: self._tray_call(self._quit_from_tray)),
        )
        self._tray_icon = pystray.Icon("desktop_vista", image, APP_NAME, menu)
        threading.Thread(target=self._tray_icon.run, name="vista-tray", daemon=True).start()

    def _tray_call(self, fn) -> None:
        # Marshal onto the Tk main loop — never touch widgets from the tray thread.
        self.after(0, fn)

    def _tray_current_label(self) -> str:
        if 0 <= self.index < len(self.images):
            return f"Current: {Path(self.images[self.index]).name}"
        return "Current: (none)"

    def _tray_next_and_set(self) -> None:
        self._next()
        self._set_wallpaper()

    def _tray_prev_and_set(self) -> None:
        self._prev()
        self._set_wallpaper()

    def _restore_from_tray(self) -> None:
        self.deiconify()
        self.lift()
        self.focus_force()

    def _on_close(self) -> None:
        # Replace destroy-on-close with hide-to-tray when tray is active.
        if getattr(self, "_tray_icon", None) is not None:
            self._save()
            self.withdraw()
            self._set_status("Running in the system tray.")
            return
        self._save()
        self.destroy()

    def _quit_from_tray(self) -> None:
        self._stop_slideshow()
        self._save()
        if getattr(self, "_tray_icon", None) is not None:
            self._tray_icon.stop()
        self.destroy()
```

**CLI:** parse `sys.argv` for `--minimized` before `DesktopVista().mainloop()`; if set, `withdraw()` after `_build_ui` / `_restore_state` and start the tray immediately. Register under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` with a quoted path plus `--minimized`.

**Slideshow note:** Keep using `self.after` (as `_schedule_next` does today). Do not move wallpaper ticks onto the tray thread.

### 2.2 Per-monitor wallpaper via `IDesktopWallpaper` (comtypes)

**Problem:** Today’s `set_windows_wallpaper` is intentionally global. Multi-monitor needs `IDesktopWallpaper::SetWallpaper(monitorId, path)`.

**Preferred stack:** `comtypes` (IDL-friendly). Fallback: document a subprocess helper only if COM binding proves fragile — still call COM, never invent a fake shell API.

**Panoramic span:** keep today’s Registry `Span` (`WallpaperStyle=22`) for true multi-monitor span images; use per-monitor set only when the user assigns **different** images per display. Ultrawide single displays remain Fill/Fit/Centre on that one ID.

### 2.3 Async pre-decode + LRU cache (no UI stutter)

**Problem:** `_show_current` opens, drafts, converts, and thumbnails on the UI thread. Large folders + tray “Next” under slideshow will hitch.

**Pattern:** Worker thread decodes to a `CTkImage`-ready RGB thumbnail; main thread only swaps `self._preview_ref`. Cap memory with an LRU keyed by `(path, mtime, PREVIEW_W, PREVIEW_H)`.

```python
import queue
import threading
from collections import OrderedDict
from dataclasses import dataclass


@dataclass
class _Decoded:
    path: str
    width: int
    height: int
    rgb_image: object  # PIL.Image.Image RGB thumbnail


class PreviewCache:
    """Small LRU of preview-sized RGB images — matches PREVIEW_W/H decode policy."""

    def __init__(self, capacity: int = 48) -> None:
        self.capacity = capacity
        self._data: OrderedDict[str, _Decoded] = OrderedDict()
        self._lock = threading.Lock()

    def get(self, path: str) -> _Decoded | None:
        with self._lock:
            item = self._data.get(path)
            if item is not None:
                self._data.move_to_end(path)
            return item

    def put(self, item: _Decoded) -> None:
        with self._lock:
            self._data[item.path] = item
            self._data.move_to_end(item.path)
            while len(self._data) > self.capacity:
                self._data.popitem(last=False)


class PreviewDecoder:
    """
    Background decode queue. UI calls request(path); results arrive via
    self.after(0, …) exactly like tray marshalling.
    """

    def __init__(self, app: "DesktopVista", cache: PreviewCache) -> None:
        self.app = app
        self.cache = cache
        self._q: queue.Queue[str | None] = queue.Queue()
        self._latest: str | None = None  # drop stale frames if user clicks quickly
        self._thread = threading.Thread(target=self._worker, name="vista-decode", daemon=True)
        self._thread.start()

    def request(self, path: str) -> None:
        hit = self.cache.get(path)
        if hit is not None:
            self.app.after(0, lambda: self.app._apply_decoded(hit))
            return
        self._latest = path
        self._q.put(path)

    def _worker(self) -> None:
        while True:
            path = self._q.get()
            if path is None:
                return
            try:
                with Image.open(path) as im:
                    width, height = im.size
                    im.draft("RGB", (PREVIEW_W, PREVIEW_H))
                    im = im.convert("RGB")
                    im.thumbnail((PREVIEW_W, PREVIEW_H), Image.LANCZOS)
                    decoded = _Decoded(path, width, height, im.copy())
                self.cache.put(decoded)
                # Only apply if this path is still the newest request.
                if path == self._latest:
                    self.app.after(0, lambda d=decoded: self.app._apply_decoded(d))
            except Exception as exc:
                if path == self._latest:
                    self.app.after(0, lambda e=exc, p=path: self.app._preview_failed(p, e))


# Inside DesktopVista (conceptual):
#   self._preview_cache = PreviewCache()
#   self._decoder = PreviewDecoder(self, self._preview_cache)
#   def _show_current(self):
#       path = self.images[self.index]
#       self._decoder.request(path)   # replaces inline Image.open block
#   def _apply_decoded(self, decoded: _Decoded):
#       self._preview_ref = ctk.CTkImage(
#           light_image=decoded.rgb_image, dark_image=decoded.rgb_image,
#           size=decoded.rgb_image.size)
#       self.preview.configure(image=self._preview_ref, text="")
#       ... update meta / _save as today ...
```

**Prefetch:** on `_next` / slideshow tick, also `request(self.images[(self.index + 1) % n])` so the following frame is warm.

**Fisher–Yates deck (Track D, trivial, ship in v1.1):**

```python
def _rebuild_shuffle_deck(self) -> None:
    self._shuffle_deck = list(range(len(self.images)))
    # In-place Fisher–Yates — every index once before reshuffle.
    for i in range(len(self._shuffle_deck) - 1, 0, -1):
        j = random.randint(0, i)
        self._shuffle_deck[i], self._shuffle_deck[j] = self._shuffle_deck[j], self._shuffle_deck[i]
    self._deck_pos = 0

def _random(self) -> None:
    if not self.images:
        return
    if not getattr(self, "_shuffle_deck", None) or self._deck_pos >= len(self._shuffle_deck):
        self._rebuild_shuffle_deck()
    # Prefer a different image when possible without breaking the deck contract.
    self.index = self._shuffle_deck[self._deck_pos]
    self._deck_pos += 1
    self._show_current()
```

Rebuild the deck whenever `_load_folder` / playlist membership changes.

### 4.3 Backward compatibility

1. **Load:** start from `DEFAULT_CONFIG` (v1 keys), `cfg.update(json)`, then `_migrate_config(cfg)`:
   - If `schema_version` missing → treat as 1; set `schema_version = 2` in memory but **do not** require new keys.
   - Missing `tray`, `playlists`, etc. → fill safe defaults (`tray.enabled=False` until user opts in, or `True` once pystray ships — product call; recommend default **enabled** only after tray is stable).
2. **Save:** always write v1 keys so older builds can still read core state; unknown keys ignored by v1.
3. **Intervals:** unknown `interval` labels fall back to `"15 minutes"` (mirror today’s `SLIDESHOW_INTERVALS` lookup). Custom seconds live beside the label, not instead of it.
4. **Folders offline:** keep paths in `folders` / playlists forever; mark UI “(offline)” when `Path.exists()` is false — do not auto-purge (matches “No files are deleted” remove-folder dialogue spirit).
