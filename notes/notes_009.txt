## 2. Architectural Blueprints & Code Snippets

Scope: patterns for what is **still open or needs hardening** — not a re-teach of shipped tray residency. British English comments. House rules unchanged:

- Tk owns the UI thread; workers publish plain data; only Tk polls / applies widgets  
- One wallpaper authority (Desktop Vista’s controller — never `IDesktopWallpaper` slideshow APIs)  
- `SetPosition` is global; per-monitor crop must be pre-rendered  
- COM device paths are session-ephemeral — never primary keys  
- On COM failure: **never** silent SPI fallback (would stamp every screen)  
- No NumPy, no pywin32; no silent geolocation; no fake Narrator mode  

### 2.1 `pystray` + Tk marshal (short reference)

Tray callbacks arrive on the pystray thread. They must **enqueue** commands; only the Tk thread drains the queue via `after`.

```python
# Tray / worker → Tk: enqueue only. Never call widget methods or self.after
# from the pystray thread (Tcl is not thread-safe).
import queue

class DesktopVista:
    def __init__(self, ...):
        self._ui_cmds: queue.SimpleQueue = queue.SimpleQueue()
        self.after(50, self._drain_ui_cmds)

    def _post_ui(self, fn, *args) -> None:
        self._ui_cmds.put((fn, args))

    def _drain_ui_cmds(self) -> None:
        try:
            while True:
                fn, args = self._ui_cmds.get_nowait()
                fn(*args)
        except queue.Empty:
            pass
        self.after(50, self._drain_ui_cmds)

    # pystray menu handler (runs off Tk):
    def _on_tray_next(self, icon, item) -> None:
        self._post_ui(self._next_and_apply)  # not self._next()
```

### 2.2 `IDesktopWallpaper` ctypes sketch + never-silent-SPI rule

```python
# Opt-in COM apply. Failures surface to the user; never fall through to
# SystemParametersInfoW (that would paint every monitor with one image).
import ctypes
from ctypes import wintypes

CLSID_DesktopWallpaper = "{C2CF3110-460E-4FC1-B9D0-8A1C0C9CC4BD}"
IID_IDesktopWallpaper = "{B92B56A9-8B55-4E14-9A89-0199BBB6F93B}"

def apply_com_wallpaper(monitor_id: str | None, path: str, *, position: int) -> None:
    """Raise on any COM failure. Caller shows the error; no SPI fallback."""
    wall = _create_desktop_wallpaper()  # CoCreateInstance via ctypes
    try:
        hr = wall.SetWallpaper(monitor_id, path)  # None => all monitors
        if hr:
            raise OSError(f"SetWallpaper failed: HRESULT 0x{hr & 0xFFFFFFFF:08X}")
        hr = wall.SetPosition(position)  # GLOBAL — not per-monitor
        if hr:
            raise OSError(f"SetPosition failed: HRESULT 0x{hr & 0xFFFFFFFF:08X}")
    finally:
        _release(wall)

# Device paths from GetMonitorDevicePath are session-ephemeral.
# Persist fingerprints (EDID/size/origin/primary/orientation), never the path.
```

**v2.0 gate reminder:** keep `"wallpaper_target": "spi"` as default until two physical displays prove independent COM apply through dock/undock and `WM_DISPLAYCHANGE`.

### 2.3 Async pre-decode + bounded LRU preview cache

Workers decode; they publish `(token, path, photo_image_bytes_or_error)` onto a queue. Tk alone constructs `CTkImage` / assigns the label.

```python
from collections import OrderedDict
from concurrent.futures import ThreadPoolExecutor
import queue

PREVIEW_CACHE_MAX = 24  # bounded; drop least-recently-used

class PreviewCache:
    def __init__(self) -> None:
        self._lru: OrderedDict[str, object] = OrderedDict()

    def get(self, key: str):
        if key in self._lru:
            self._lru.move_to_end(key)
            return self._lru[key]
        return None

    def put(self, key: str, value: object) -> None:
        self._lru[key] = value
        self._lru.move_to_end(key)
        while len(self._lru) > PREVIEW_CACHE_MAX:
            self._lru.popitem(last=False)

# Worker publishes data only — never touches Tk widgets.
def _decode_preview(path: str, token: int, out: queue.SimpleQueue) -> None:
    try:
        rgb = _load_rgb_thumbnail(path)  # Pillow + EXIF off-thread
        out.put(("ok", token, path, rgb))
    except Exception as exc:
        out.put(("err", token, path, str(exc)))

# Tk poller:
def _poll_preview_results(self) -> None:
    try:
        while True:
            kind, token, path, payload = self._preview_q.get_nowait()
            if token != self._load_token:
                continue  # stale navigation
            if kind == "ok":
                self._preview_cache.put(path, payload)
                self._paint_preview(payload)
            else:
                self._show_preview_error(payload)
    except queue.Empty:
        pass
    self.after(16, self._poll_preview_results)
```
