3.1 Multi-monitor independent playback controller + state machine
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Today (v1.8): one shared index / shuffle deck / schedule clock inside
DesktopVista. windows_wallpaper_com.py can target a monitor_id for a single
apply, but navigation and slideshow remain global. Independence is unverified.

Target (v2.0, hardware-gated): extract PlaybackController so each fingerprinted
display owns its own deck, index, pause reasons, and optional schedule mode,
while Tk still owns UI and a single ApplyQueue serialises COM/SPI writes.

ASCII overview:

  ┌──────────────── DesktopVista (Tk owner) ─────────────────┐
  │  DisplaysPage ──► DisplayRegistry (fingerprints)         │
  │       │                    │                             │
  │       ▼                    ▼                             │
  │  AssignmentMap     PlaybackHub                           │
  │  (fp → source)        │                                  │
  │                       ├─ Controller[fp_primary]          │
  │                       │     state: IDLE|RUNNING|PAUSED   │
  │                       │     images[], shuffle[], index   │
  │                       │     history ring (per display)   │
  │                       └─ Controller[fp_secondary] …      │
  │                              │                           │
  │                              ▼                           │
  │                         ApplyQueue ──► SPI | COM STA     │
  └──────────────────────────────────────────────────────────┘

Mermaid:

```mermaid
stateDiagram-v2
  [*] --> Idle
  Idle --> Running: user_start / schedule_due
  Running --> PausedBattery: battery_saver
  Running --> PausedFullscreen: fullscreen
  Running --> PausedUser: toggle
  PausedBattery --> Running: saver_clear ∧ intent_running
  PausedFullscreen --> Running: fs_clear ∧ intent_running
  PausedUser --> Running: toggle
  Running --> Applying: next_tick / hotkey_next
  Applying --> Running: apply_ok
  Applying --> Faulted: apply_fail (surface error; no SPI fallback)
  Faulted --> Idle: user_ack
  note right of Applying
    ApplyQueue: one COM call at a time
    never on Tk thread
  end note
```

Python pattern (illustrative — extract to playback.py in v2.0):

```python
from dataclasses import dataclass, field
from enum import Enum, auto
from collections import deque
from typing import Optional

class PlayState(Enum):
    IDLE = auto()
    RUNNING = auto()
    PAUSED_USER = auto()
    PAUSED_BATTERY = auto()
    PAUSED_FULLSCREEN = auto()
    APPLYING = auto()
    FAULTED = auto()

@dataclass
class PlaybackController:
    """One independent slideshow pipeline per fingerprinted display."""
    fingerprint: str
    images: list[str] = field(default_factory=list)
    shuffle_order: list[int] = field(default_factory=list)
    index: int = 0
    state: PlayState = PlayState.IDLE
    intent_running: bool = False  # user intent ≠ scheduled tick
    history: deque[str] = field(default_factory=lambda: deque(maxlen=100))
    style: str = "Fill"
    pause_reasons: set[str] = field(default_factory=set)

    def can_tick(self) -> bool:
        return self.intent_running and not self.pause_reasons and self.images

    def advance(self) -> Optional[str]:
        if not self.can_tick():
            return None
        # Fisher–Yates deck already built; cursor advance mirrors v1.8
        self.index = (self.index + 1) % len(self.images)
        path = self.images[self.shuffle_order[self.index] if self.shuffle_order
                           else self.index]
        return path

    def note_applied(self, path: str) -> None:
        self.history.append(path)
```

DisplayRegistry fingerprint (never persist COM path):

```python
@dataclass(frozen=True)
class MonitorFingerprint:
    edid_hash: str          # empty string if EDID unavailable
    width: int
    height: int
    origin_x: int
    origin_y: int
    is_primary: bool
    orientation: int        # DMDO_* 

    def key(self) -> str:
        return "|".join([
            self.edid_hash or "no-edid",
            f"{self.width}x{self.height}",
            f"@{self.origin_x},{self.origin_y}",
            "P" if self.is_primary else "S",
            str(self.orientation),
        ])
```

Reconciliation on WM_DISPLAYCHANGE / resume / dock:
  1. Re-enumerate GDI monitors + COM paths.
  2. join_monitor_topology (already shipped) for session COM routing.
  3. Match new geometry to persisted fingerprints by EDID then max RECT
     intersection; mark unresolved rather than guessing (Mark notes_008).
  4. Remap PlaybackController instances; never key config by COM path.

Exit criterion for enabling COM default: two different images visible on two
physical displays after a dock/undock cycle, with fingerprints stable across
the cycle and unresolved displays labelled — not guessed.

```sql
-- desktop_vista.db — SQLite 3, WAL, UTF-8
PRAGMA journal_mode=WAL;
PRAGMA foreign_keys=ON;

CREATE TABLE schema_meta (
    key   TEXT PRIMARY KEY,
    value TEXT NOT NULL
);
INSERT INTO schema_meta(key, value) VALUES ('schema_version', '1');

CREATE TABLE sources (
    id          TEXT PRIMARY KEY,          -- playlist id or folder path hash
    kind        TEXT NOT NULL CHECK (kind IN ('folder','playlist','collection','feed')),
    name        TEXT NOT NULL,
    root_path   TEXT,                      -- folder / playlist primary path
    offline     INTEGER NOT NULL DEFAULT 0,
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL
);

CREATE TABLE images (
    id            TEXT PRIMARY KEY,        -- stable hash of normalised path
    path          TEXT NOT NULL UNIQUE,
    source_id     TEXT REFERENCES sources(id) ON DELETE SET NULL,
    width         INTEGER,
    height        INTEGER,
    mtime_ns      INTEGER,
    file_size     INTEGER,
    exif_dt       TEXT,
    gps_lat       REAL,
    gps_lon       REAL,
    perceptual_hash TEXT,                  -- dhash hex when computed
    favourite     INTEGER NOT NULL DEFAULT 0,
    hidden        INTEGER NOT NULL DEFAULT 0,
    last_applied  TEXT,
    created_at    TEXT NOT NULL,
    updated_at    TEXT NOT NULL
);
CREATE INDEX idx_images_hidden ON images(hidden);
CREATE INDEX idx_images_fav ON images(favourite);
CREATE INDEX idx_images_phash ON images(perceptual_hash);

CREATE TABLE tags (
    image_id  TEXT NOT NULL REFERENCES images(id) ON DELETE CASCADE,
    tag       TEXT NOT NULL,               -- exact-string, case-sensitive (as-built)
    PRIMARY KEY (image_id, tag)
);
CREATE INDEX idx_tags_tag ON tags(tag);

CREATE TABLE playlists (
    id          TEXT PRIMARY KEY,
    name        TEXT NOT NULL,
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL
);

CREATE TABLE playlist_folders (
    playlist_id TEXT NOT NULL REFERENCES playlists(id) ON DELETE CASCADE,
    folder_path TEXT NOT NULL,
    position    INTEGER NOT NULL DEFAULT 0,
    PRIMARY KEY (playlist_id, folder_path)
);

CREATE TABLE collections (
    id          TEXT PRIMARY KEY,
    name        TEXT NOT NULL,
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL
);

CREATE TABLE collection_tags (
    collection_id TEXT NOT NULL REFERENCES collections(id) ON DELETE CASCADE,
    tag           TEXT NOT NULL,
    PRIMARY KEY (collection_id, tag)
);

-- Fingerprint string = MonitorFingerprint.key(); NEVER a COM device path
CREATE TABLE display_assignments (
    fingerprint   TEXT PRIMARY KEY,
    image_id      TEXT REFERENCES images(id) ON DELETE SET NULL,
    style         TEXT NOT NULL DEFAULT 'Fill',
    source_kind   TEXT,                    -- folder|playlist|collection
    source_id     TEXT,
    updated_at    TEXT NOT NULL
);

CREATE TABLE history (
    id           INTEGER PRIMARY KEY AUTOINCREMENT,
    fingerprint  TEXT,                     -- NULL = legacy shared pipeline
    image_id     TEXT REFERENCES images(id) ON DELETE SET NULL,
    path         TEXT NOT NULL,            -- denormalised for orphan survival
    applied_at   TEXT NOT NULL
);
CREATE INDEX idx_history_fp_time ON history(fingerprint, applied_at DESC);
```

Zero-data-loss migration from config.json v1.8:

```
Phase M0 (read-only audit):
  Load config.json via existing _validate_config; count folders, playlists,
  collections, tags, favourites, hidden, history from playback_state.json.

Phase M1 (create DB + dual-write):

  favourites/hidden flags; history ring → history (fingerprint NULL).
  From this point: every save_config ALSO upserts SQLite (dual-write).

Phase M2 (cut-over read):

Phase M3 (config slim — optional, later):
  Keep user prefs (tray, hotkeys, ui, solar, schedule, wallpaper_target) in

```
